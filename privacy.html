Northstar Personal Calendar
Overview Privacy Terms

Privacy

Your calendar data stays within the private service.

Northstar Personal Calendar is for one user. These pages describe how its Google authorization and calendar data are handled.

Information accessed

Google sign-in uses OpenID and email identity information. The app requests permission to view Calendar events. This integration reads the primary calendar and displays up to six current or upcoming events, including their date, time, title, and location when available. Responses may contain additional events that are filtered before display.

Storage and display

Authorization tokens persist in restrictive files on the service owner’s private Mac. Calendar events are handled by the private server and held in browser memory for display. Event data and tokens are excluded from browser startup and saved previews.

Use and control

This app does not use advertising, sell data, or use third-party analytics. The Calendar integration does not include AI processing or model training.

You can revoke access through your Google Account permissions. The service owner can remove the local authorization. Revoking access prevents further reads until authorization is granted again.

Optional YouTube connection

If enabled, Northstar uses YouTube API Services to read the authorized channel’s identity, recent upload metadata and owner Analytics reports: views, watch time, average viewing duration and percentage, subscriber gains and losses, daily performance, traffic sources and selected-video audience retention when available. Google OpenID and verified email identify the authorizing account. Access is read-only; Northstar cannot upload, publish, change videos, or manage the channel.

YouTube authorization tokens are kept in the service owner’s macOS Keychain, separately from Calendar authorization. Reports and video metadata are requested on demand and held in server and browser memory for display. Northstar does not persist these API responses in the Vault, browser storage, startup previews or report files. User-written project notes and manual observations are separate records.

The YouTube integration does not sell or share API data, display advertising, use third-party tracking, or send API data for AI processing or model training. Google handles authorization and YouTube API requests under Google’s Privacy Policy.

Use Disconnect YouTube in Northstar to revoke this connection and remove its local Keychain authorization. If disconnection fails, Northstar reports the failure so you can retry. You can also revoke access through Google Account permissions. Reload or close the report to clear its display; there is no saved API report to delete. Google revocation removes the consenting account’s access across clients in the same Google Cloud project. If that account also connected Calendar in this project, Calendar will need reconnecting. Separate client IDs alone do not isolate revocation.

Public information pages

These information pages are hosted publicly by GitHub Pages. Google handles account sign-in and Calendar access. Each provider has its own privacy practices. The public pages contain no calendar data or tokens and have no access to the dashboard. They provide no private dashboard URL.

For support, contact the owner who provided this private app.
